Network

Results move with the seed — a different draw of the same architecture holds altitude anywhere from a quarter to all of the time, and the share of neurons that fire at all moves with it. Rebuilding on a few seeds is the honest way to read any result here.

Tonic drive decides whether the network listens. Raise it and the pool fires happily on its own while the aircraft's state becomes undecodable from the motor pool — the same wiring, no longer paying attention.

Eight flights, each removing one component, so the hover can be attributed to whatever actually changes it. Takes a minute or so and runs in slices, so the page keeps moving.

One camera, watching a hand, exactly as described. Skin-tone segmentation — crude, and shown to you so you can see when it is wrong. Nothing leaves this device.

Propellers cut. This app's own measurements say the control law here may fail without warning, and the gesture input puts a hand in front of the aircraft. Bench it with the propellers off unless it is inside a net.

What this is

An apparatus for testing a claim: that a reconstructed fruit fly brain, fed nothing but a camera watching a hand, flew a drone with no control logic of any kind. Every part of that arrangement is built here, and every part can be removed while the rest keeps running, which is the only way to find out what any of it was doing.

What it is not

  • It is not a fly brain. No published connectome is shipped with this app. The network is generated to match published summary statistics — size ratio, excitatory fraction, degree tail, synaptic weight distribution. Nothing in it corresponds to an identified neuron. A real edge list can be imported, and then the provenance line says so instead.
  • It is not a real drone. The airframe is a rigid-body model with motor lag, drag, gusts and an untrimmed centre of mass. It contains no stabilisation whatsoever, which is checkable: constant throttle tumbles it in under half a second.
  • It cannot tell you what happened in someone else's video. It can only establish what evidence such a video would need to carry before the claim in it is worth believing — and none of that evidence is expensive to produce.

                                Sonar map

                                No sonar

                                Beam returns build an occupancy map — free water in front of the return, bottom or obstacle at it, the beam drawn as the cone it actually is. Underwater there is no satellite fix, so the position drifts; each scan is matched against the map already built to pull it back, and the drift estimate is shown rather than hidden.

                                No sonar is attached. A rehearsal generates synthetic returns from a made-up dam so the mapping can be seen working — every number it produces is synthetic and badged as modelled.

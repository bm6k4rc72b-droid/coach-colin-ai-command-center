The Reference Card

The equations and estimates this course actually uses, collected. If you can reconstruct this page from memory, you have the course.

Learning

\hat{\theta}_{\text{MLE}} = \argmax_\theta \sum_i \log p_\theta(y_i \mid x_i) \qquad \theta_{t+1} = \theta_t - \eta \nabla_\theta L
\E\big[(y-\hat f)^2\big] = \text{bias}^2 + \text{variance} + \sigma^2
\KL(p\|q) = \E_{p}\!\left[\log \tfrac{p}{q}\right] \ge 0, \qquad H(p,q) = H(p) + \KL(p\|q)
\text{perplexity} = e^{\ell_{\text{nats}}}, \qquad \text{bits/token} = \ell_{\text{nats}} / \ln 2

Deep networks

\delta^{(\ell)} = \big(W^{(\ell+1)}\big)\!\T \delta^{(\ell+1)} \odot \phi'\big(z^{(\ell)}\big), \qquad \nabla_{W^{(\ell)}} L = \delta^{(\ell)}\big(a^{(\ell-1)}\big)\!\T
\operatorname{Var}(W_{\text{He}}) = \frac{2}{n_{\text{in}}}, \qquad \operatorname{Var}(W_{\text{Xavier}}) = \frac{2}{n_{\text{in}} + n_{\text{out}}}
\theta_{t+1} = \theta_t - \eta\,\frac{\hat m_t}{\sqrt{\hat v_t}+\epsilon} - \eta\lambda\theta_t \quad\text{(AdamW)}

Transformers
